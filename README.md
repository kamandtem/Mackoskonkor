# کنکور من

اپلیکیشن آفلاین شمارش معکوس، برنامه‌ریزی درسی، تایمر تمرکز و تست‌زنی سرعتی برای داوطلبان کنکور.
رابط فارسی و راست‌به‌چپ، ذخیره‌سازی کاملاً محلی، بدون حساب کاربری و بدون نیاز به اینترنت.

## تغییرات نسخه ۲.۶

- کارت شمارش معکوس خانه حالا با لمس، بدون تغییر منطق شمارشگر، به کارت مسیر کوهستانی برمی‌گردد.
- پشت کارت، مسیر پیشرفت از شروع تا قله با نقاط مرحله‌ای و نشانگر زنده «تو» نمایش داده می‌شود.
- جایگاه کاربر از درصد پیشرفت واقعی محاسبه می‌شود و با تغییر روزها و تاریخ آزمون به‌روز می‌ماند.
- دکمه‌های جلوی کارت مثل تغییر تاریخ و شروع پومودورو همچنان مستقل و سالم کار می‌کنند.

## تغییرات نسخه ۲.۵

- زیر هدر خانه، نوار انگیزشی چرخشی با ۲۰ جمله کوتاه اضافه شد.
- زیر شمارش معکوس، کارت‌های متحرک خبرهای سنجش و آزمون‌های آزمایشی اضافه شدند.
- کارت سنجش به sanjesh.org و کارت آزمون‌ها به منابع مؤسسات لینک می‌شود؛ تلاش اتصال آنلاین انجام می‌شود و در نبود دسترسی، کارت‌های راهنمای آفلاین نمایش داده می‌شوند.

## تغییرات نسخه ۲.۴

- بخش فلش‌کارت با آیکن مستقل به منوی اصلی اضافه شد.
- دسته‌های انگلیسی، عربی و فارسی با تفکیک دهم، یازدهم و دوازدهم اضافه شدند.
- کارت‌ها با چرخش سه‌بعدی، ترجمه، مثال، منبع، جست‌وجو، فیلتر پایه، نشان‌دارکردن و ثبت «بلدم» کار می‌کنند.
- پیشرفت مرور فلش‌کارت‌ها به‌صورت آفلاین روی دستگاه ذخیره می‌شود.
- بانک اولیه بر اساس عناوین و واژه‌های کتاب‌های رسمی متوسطه دوم و محورهای پرتکرار آزمون سامان‌دهی شده و ساختار داده برای تکمیل واژه‌نامه‌های چاپی آماده است.

## تغییرات نسخه ۲.۳

- یادداشت روزانه از صفحه تقویم حذف شد و به عنوان مستقل منوی دکمه شناور + منتقل شد.
- صفحه فهرست یادداشت‌ها با کارت‌های سنجاقی، کاغذ خط‌دار، رنگ‌بندی و چیدمان نامنظم طراحی شد.
- محیط نوشتار هر یادداشت شامل عنوان، کاغذ خط‌دار، ذخیره محلی، و حذف یادداشت است.
- یادداشت‌ها در LocalStorage ذخیره و همراه فایل پشتیبان صادر و بازیابی می‌شوند.

## تغییرات نسخه ۲.۲

- آیکن رسمی برنامه از تصویر جدید برند استفاده می‌کند و در وب، PWA و آیکن لانچر اندروید یکسان است.
- اسپلش‌اسکرین برند با حلقه‌های بسیار آرام و پیام کوتاه شروع برنامه اضافه شد.
- هنگام فعال‌بودن تایمر پومودورو، سه حلقه‌ی تو در تو با سرعت‌های متفاوت و خیلی آهسته روی هم حرکت می‌کنند؛ با توقف تایمر، حرکت متوقف می‌شود.

## تغییرات نسخه ۲.۱

- اتاق مطالعه مجازی با پرتره‌های واقعی، مدارهای زنده، وضعیت حضور و حرکت کم‌حواس‌پرتی بازطراحی شد.
- اتاق خصوصی به‌جای ورود مستقیم، جریان درخواست عضویت و بازخورد روشن دارد.
- پروفایل مشاوران و مدرسان تصویری شد و اقدام‌های رزرو و درخواست طرح بازخورد درون‌صفحه‌ای دارند.
- انتخاب درس در تقویم به پایه، کتاب رسمی، کد کتاب و فصل‌های همان چاپ متصل شد.
- منابع کنکور ۱۴۰۵ و چاپ‌های ۱۴۰۲ دهم، ۱۴۰۳ یازدهم و ۱۴۰۴ دوازدهم پوشش داده شدند.

## تغییرات نسخه ۲

### برنامه با اطلاعات خودِ کاربر شروع می‌شود
پیش‌تر برنامه با یک پروفایل نمونه («کنکوری پرتلاش»)، پنج تسک، چهار جلسه‌ی مطالعه و سه آزمون
از پیش پر شده بود. الان:

- در اجرای اول فقط صفحه‌ی ورود اطلاعات باز می‌شود (نام، رشته، تاریخ کنکور، هدف روزانه).
- تا وقتی این مرحله کامل نشود هیچ عددی نمایش داده نمی‌شود.
- کاربری که قبلاً از برنامه پشتیبان گرفته، همان‌جا فایلش را بارگذاری می‌کند و برنامه با
  اطلاعات خودش بالا می‌آید.
- همه‌ی بخش‌ها حالت خالی مشخص با راهنمای قدم بعدی دارند.

### منو
- آیکن‌های چرخ‌دنده و «بیشتر» حذف شدند.
- منوی اصلی با لمس عکس کاربر در هدر باز می‌شود و تنظیمات داخل همان منو است.
- هر آیتم منو یک صفحه‌ی واقعی دارد؛ گزینه‌ی بی‌مقصد در منو نیست.

### تست‌زنی سرعتی (بخش جدید)
کرنومتر سؤال‌به‌سؤال با ثبت درست/غلط/نزده، محاسبه‌ی درصد کنکوری
(`((۳×صحیح) − غلط) ÷ (۳×کل)`)، سرعت متوسط، کندترین سؤال، نمودار زمان هر سؤال و تاریخچه.
هر جلسه در آمار مطالعه هم ثبت می‌شود.

### اصلاح منطق
- **آمار:** اعداد ثابتی مثل `+۱۲۰۰ دقیقه`، `+۲۸ جلسه` و نمودار هفتگی دستی حذف شدند؛
  همه‌ی آمار از جلسات واقعی کاربر ساخته می‌شود.
- **استریک:** پیش‌تر با هر روز جدید فقط زیاد می‌شد و هرگز صفر نمی‌شد. الان از روزهای
  متوالی دارای مطالعه محاسبه می‌شود و رکورد هم واقعی است.
- **شمارش معکوس آزمون‌ها:** «۱۴ روز مانده» ثابت بود؛ الان از تاریخ ثبت‌شده حساب می‌شود و
  آزمون‌های برگزارشده جدا نمایش داده می‌شوند.
- **برنامه‌ی فردا:** تب «فردا» همان تسک‌های امروز را نشان می‌داد؛ الان تسک‌ها بر اساس
  تاریخ تفکیک و بر اساس ساعت مرتب می‌شوند.
- **«الان چی بخونم؟»:** به‌جای اولین تسک ناتمام، تسک متناظر با ساعت فعلی انتخاب می‌شود و
  حالت عقب‌افتادگی هم پیام مخصوص دارد.
- **تاریخ:** ساعت و تاریخ با رقم لاتین ذخیره و فقط در نمایش فارسی می‌شوند. کبیسه‌ی شمسی از
  خود توابع تبدیل استخراج می‌شود (تست‌شده روی ۸۰۰۰ روز پیوسته).
- **منطقه‌ی زمانی:** `toISOString` جای خود را به تاریخ محلی داد؛ پیش‌تر بین نیمه‌شب تا
  ۳:۳۰ بامداد به وقت تهران، مطالعه روی روز قبل ثبت می‌شد.
- **تغییر رشته:** قبلاً دروس عوض نمی‌شد؛ الان با تأیید کاربر جایگزین می‌شود و آمار حفظ می‌ماند.
- **دروس هنر و زبان:** پیش‌تر وجود نداشت و به دروس تجربی برمی‌گشت.
- **تایمر تمرکز:** با تنظیمات پومودورو‌ی کاربر هم‌تراز شد و حلقه‌ی بازسازی هر ثانیه‌ی
  `setInterval` برطرف شد.
- **ورودی‌ها:** همه‌ی داده‌های خوانده‌شده از حافظه اعتبارسنجی می‌شوند؛ فایل خراب برنامه را
  از کار نمی‌اندازد.
- **تاریخ شمسی:** انتخابگر سال/ماه/روز شمسی جای ورودی متنی و `input[type=date]` میلادی را گرفت.

### پشتیبان‌گیری
گرفتن فایل `JSON` از همه‌ی داده‌ها و بازگردانی آن از منو یا از صفحه‌ی اول.

## اجرا

```bash
npm install
npm run dev      # اجرا روی http://localhost:3000
npm run build    # خروجی وب در dist/
npm run lint     # بررسی تایپ‌ها
```

## ساخت APK

با هر push روی `main` یا اجرای دستی workflow، فایل APK ساخته و به‌عنوان artifact آپلود می‌شود:
`.github/workflows/android.yml`

به‌صورت محلی:

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

> پوشه‌ی `android/app/src/main/assets/public` خروجی تولیدی `cap sync` است و در مخزن
> نگه داشته نمی‌شود. قبل از هر بیلد اندروید، اول `npm run build` را اجرا کن.

## ساختار

```
src/
├── types/konkur.ts        مدل داده‌ها
├── utils/
│   ├── jalali.ts          تقویم شمسی، ساعت و قالب‌بندی
│   ├── storage.ts         ذخیره‌سازی محلی، اعتبارسنجی، پشتیبان‌گیری
│   ├── stats.ts           محاسبه‌ی همه‌ی آمار از داده‌ی واقعی
│   └── soundEngine.ts     تولید صدای محیط با Web Audio
└── components/            رابط کاربری
```

اطلاعات فقط در `localStorage` همان دستگاه ذخیره می‌شود و به هیچ سروری ارسال نمی‌شود.
